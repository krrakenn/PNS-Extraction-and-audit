Step 1 — Pre-Processing

kibana_toinput.go

Input:Raw Kibana CSV (e.g. Untitled discover search.csv)
Output:csv_batch_tool/input/filtered_output_20-04.csv

No LLM prompt — pure column filtering via CLI flags (-input, -output, -keep)

Step 2 — LLM Extraction

csv_batch_tool/main.go

Input:filtered_output_20-04.csv (seller_id, buyer_id, recording_url)
Output:extraction_output_.../<model>/<timestamp>/output.csv
Prompt (built in utils.go): Sends the call audio bytes along with user details (buyer name, city, seller name, city) and product category hierarchy to the LLM. Asks it to extract structured JSON covering: buyer_details, seller_details, payment, metadata, moq, next_steps, and products array with specs/prices.
Step 3a — Flat Fields Audit

Auditor/31-03_audit.py

Input:Two output.csv files (Model 1 = GT, Model 2 = Flash)
Output:audit_outputs/without_products_.../results.csv + per-URL *_audit.json, prompt.txt, usage_metadata.json
Prompt: # FLAT FIELDS AUDIT AGENT
Audits ONLY: buyer_details, seller_details, payment, metadata, moq, next_steps.
4-step pipeline:
1. Field Discovery — enumerate every key with real values
2. Value Normalization — currency, ranges, lakh/crore, phone, dates, booleans
3. Synonym Resolution — payment terms, delivery, identity, time synonyms
4. Verdicts — MATCH / PARTIAL / MISMATCH / MISSING / HALLUCINATED
Step 3b — Products Audit

Auditor/31-03_audit_products.py

Input:Two output.csv files (extracts only products array from thinking_json)
Output:audit_outputs/audit_outputs_.../results.csv + per-URL *_audit.json, audit_checks.csv
Prompt: # PRODUCTS AUDIT AGENT
Audits ONLY the products array.
5-step pipeline:
1. Product Alignment — match GT products to Flash (split/merge detection)
2. Name Attribute Extraction — material, brand, form, size tokens
3. Value Normalization — units, currency, Hindi unit names, price equivalence
4. Spec Name Synonym Resolution — thickness=gauge, packing=packaging, etc.
5. Judging — MATCH / PARTIAL / MISMATCH / MISSING / HALLUCINATED
Step 4a — Flat Collation

collate_without_products_audit_json_to_csv.py

Input:Directory of *_audit.json files from flat fields audit
Output:audit_checks_collated.csv + usage_metadata_collated.csv

No LLM prompt — pure JSON-to-CSV flattening. Optional --analyze flag triggers analysis.

Step 4b — Products Collation

collate_audit_checks.py

Input:Directory of *_audit.json files from products audit
Output:audit_checks.csv

No LLM prompt — called automatically at end of products audit run.

Step 5a — Flat Analysis

analyze_without_products_audit_report.py

Input:audit_checks_collated.csv
Output:without_products_analysis_report/ — MD report + 3 distribution CSVs (overall, section, field)

No LLM prompt — statistical analysis with match rates, per-section breakdowns, and field-level examples.

Step 5b — Products Analysis

analyze_audit_report.py

Input:audit_checks.csv or a folder of *_audit.json files
Output:analysis_report/ — MD report + 2 distribution CSVs (overall, field)

No LLM prompt — statistical analysis with match rates, field-level verdict distributions, and examples.
